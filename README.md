## 🗂️ Topics Covered So Far

### 📦 Arrays — Searching 🔄 In Progress
- ✅ **Linear Search** — Traverse array element by element. `O(n)` time, `O(1)` space.
- ✅ **Binary Search** — Divide and conquer on sorted array. `O(log n)` time, `O(1)` space.
- ✅ **2D Linear Search** — Row-by-row traversal on matrix. `O(n×m)` time, `O(1)` space.
- ✅ **2D Binary Search** — Flat index binary search on sorted matrix. `O(log(n×m))` time, `O(1)` space.
- 🔄 More searching techniques coming...

### 📦 Arrays — Sorting 🔄 In Progress
- ✅ **Bubble Sort** — Adjacent swaps with early exit optimization. `O(n²)` worst, `O(n)` best.
- ✅ **Selection Sort** — Find minimum and place it. `O(n²)` time, minimum swaps.
- ✅ **Insertion Sort** — Build sorted portion one element at a time. `O(n²)` worst, `O(n)` best.
- ✅ **Merge Sort** — Divide and conquer, always `O(n log n)`, stable sort.
- ✅ **Quick Sort** — Pivot-based divide and conquer. `O(n log n)` average, `O(n²)` worst.
- 🔄 Heap Sort, Tim Sort coming...

### 🔤 Strings 🔄 In Progress
- ✅ **Palindrome Checker** — Two-pointer technique with case-insensitive comparison. `O(n)` time, `O(1)` space.
- 🔄 More string problems coming...

### 🔗 Singly Linked List 🔄 In Progress
- ✅ **Insert at Beginning** — Update head pointer. `O(1)` time.
- ✅ **Insert at End** — Using `end` pointer for direct tail access. `O(1)` time.
- ✅ **Insert at Position** — Traverse to P-1, link new node. `O(n)` time.
- ✅ **Delete at Position** — Two-pointer traverse, bridge gap, free memory. `O(n)` time.
- 🔄 Search, Reverse coming...

### 🔗 Doubly Linked List 🔄 In Progress
- ✅ **Insert at Head** — Bidirectional link at front. `O(1)` time.
- ✅ **Insert at Head & Tail** — `O(1)` insertion at both ends using `head` and `tail` pointers.
- ✅ **Insert at Position** — 4 pointer updates for bidirectional linking. `O(n)` time.
- ✅ **Delete at Position** — Update both `prev` and `next`, handle dangling pointers. `O(n)` time.
- 🔄 Reverse traversal coming...

### 📚 Stacks 🔄 In Progress
- ✅ **Stack using STL** — push, pop, top, empty operations using `<stack>`. All `O(1)`.
- 🔄 Stack using Array, Stack using Linked List coming...

## 💡 How I Approach Each Problem

1. **Understand** — Read the problem carefully. Identify input/output.
2. **Brute Force** — Think of the simplest possible solution first.
3. **Optimize** — Analyze bottlenecks. Apply better data structures or algorithms.
4. **Code** — Write clean, well-commented code.
5. **Test** — Dry-run edge cases (empty array, single element, duplicates, etc.).
6. **Reflect** — Note the time/space complexity and key learnings.
